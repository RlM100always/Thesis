# Experiment outputs

This folder stores aggregate evidence used in the teacher-template thesis report. Raw Drive exports and customer-level predictions are deliberately excluded.

- rq1/: branch--SKU forecast metrics, baseline comparisons, bootstrap result and run manifest.
- rq2/: customer prediction metrics, customer-cluster intervals and temporal split audit.
- rq3/: supplied scenario metrics, shop-cluster intervals and historical procurement summary.
- rq4/: generated-case consistency metrics and human-study readiness status.

Scenario results are not described as observed business outcomes. RQ4 task materials are not participant responses.
