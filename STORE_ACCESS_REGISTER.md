## Security rules

- This public register contains non-sensitive access information only.
- Never add passwords, password hashes, API keys, bearer tokens, recovery links, private email addresses or secret values here.
- Send each owner their login instructions privately. Owners should set their own password and store it in a password manager.
- Never publish the Platform Admin secret or use a shared merchant account.
- Keep private owner contact details and credential-delivery records in a restricted-access register, not this public repository.
