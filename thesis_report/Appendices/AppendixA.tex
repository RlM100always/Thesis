\section{Environment Setup}

From the repository root, the tested analytical environment is Python 3.12:

\begin{lstlisting}[language=bash,caption={Create the analytical environment.}]
py -3.12 -m venv .venv312
.\.venv312\Scripts\Activate.ps1
python -m pip install -r requirements.txt
\end{lstlisting}

The synthetic research pipeline is run in order:

\begin{lstlisting}[language=bash,caption={Rebuild the synthetic research artifacts.}]
python 00_normalize_dataset.py
python 01_preprocessing.py
python 01b_customer_features.py
python 02_classification.py
python 02b_classification_v2.py
python 03_clustering.py
python 04_forecasting.py
python 05_shap_analysis.py
python 06_final_report.py
python 07_return_prediction.py
python 08_churn_prediction.py
\end{lstlisting}

The public-real validation and market-price benchmarks are rebuilt with:

\begin{lstlisting}[language=bash,caption={Rebuild the public-real experiments.}]
python -m ml.real_data_validation
python -m ml.market_prices --all
\end{lstlisting}

An organization-specific canonical export can be trained with:

\begin{lstlisting}[language=bash,caption={Train on a canonical SME export.}]
python -m ml.real_pipeline --input path\to\bsmart_sales_anonymized.csv
\end{lstlisting}

\section{Application and Verification}

\begin{lstlisting}[language=bash,caption={Run the application and checks.}]
# terminal 1
python run_api.py

# terminal 2
cd frontend
npm install
npm run dev

# verification
cd ..
python -m pytest -q
cd frontend
npm run build
\end{lstlisting}

The local dashboard is normally available at
\url{http://localhost:5173}; interactive API documentation is available at
\url{http://127.0.0.1:8000/docs}.

\section{Reproducibility Notes}

The repository excludes large regenerable outputs from version control but keeps
the source dataset and report figures needed for review. LSTM output can move
slightly across runs due to early stopping/backend nondeterminism; stored artifact
metrics must therefore be quoted consistently. Synthetic, public-real and primary
real artifacts use separate paths and must not be averaged into one reported
number.
